# CodeVerse

CodeVerse is an AI-powered project building, learning, and career readiness platform for college students.

## Architecture

- **Frontend:** Next.js 14, React, Tailwind CSS, TypeScript
- **Backend:** Node.js, Express, REST APIs, TypeScript
- **Database:** MongoDB (to be connected in Part 2)
- **AI Stack:** Google Gemini API (dedicated service layer)

## Structure

- `/client` - Next.js frontend application with premium responsive UI
- `/server` - Express backend API server

## Getting Started

### Frontend / Client

```bash
cd client
npm run dev
```
Client runs on `http://localhost:3000`

### Backend / Server

```bash
cd server
npm run build
npm start
```
Server runs on `http://localhost:5000`
